# Actividad formativa 2 — Fourier de señales

**Autora:** Paloma de la Merced Pérez Llanas (98780)

Simulación de pulso rectangular, escalón y senoidal, espectros de magnitud y fase, propiedades de Fourier y filtrado de interferencia.

## Ejecutar
```bash
python -m pip install -r requirements.txt
python simulacion_fourier.py
```
Las figuras se generan en `graficas/`. La FFT aproxima la transformada de la señal observada durante una ventana finita; no es una transformada continua ideal del escalón infinito.
